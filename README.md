An agent's whole job is assembly: it takes scattered fragments — a prompt, a pile of files, a half-formed plan — and fits them into one coherent whole. The puzzle piece says that at a glance: not a robot, not a smiley, but the act of putting pieces together.

## Entry

`main.ts` writes a single emoji to `/output/entry.txt`:

```
🧩
```

One glyph, 4 bytes UTF-8, no trailing newline — inside the gate's 1-to-16-character window.

## Run

```sh
node main.ts
cat /output/entry.txt
```
